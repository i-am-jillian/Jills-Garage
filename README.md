# Jill's Garage

Electronics and tools inventory, published with GitHub Pages.

## Deployment

The site files (`index.html`, `styles.css`, and `photos/`) live at the repository root so GitHub Pages serves the inventory instead of this README.

In **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. Commit and push the site files to `main` to publish updates. No build step is required.

Site: https://i-am-jillian.github.io/Jills-Garage/

## Editing

Edit inventory cards in `index.html`, styles in `styles.css`, and pictures in `photos/`. Open `index.html` in a browser to preview changes.
